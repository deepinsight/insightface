# Face Reconstruction and Gaze Estimation

This directory contains the following research implementations:

- [PBIDR](PBIDR/README.md): facial geometric detail recovery via implicit representation.
- [Gaze](gaze/README.md): gaze estimation with weak supervision from synthetic views.
- [JMLR](jmlr/README.md): monocular 3D face reconstruction for the ECCV 2022 WCPA challenge.
- [OSTeC](ostec/README.md): one-shot facial texture completion.

Each project documents its own environment, data, pretrained models, and usage.
