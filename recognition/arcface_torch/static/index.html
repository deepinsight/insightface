Research prototype only. The wallet payload is a random demo secret, not a funded blockchain wallet. The non-extractable WebCrypto key is stored by this browser; the EEG score is a UI gate, not a cryptographic biometric key or a production security boundary. A production design needs a threat model, secure hardware/key custody, replay protection, liveness checks, and independent security review. Use sessions 3→4 and the 0.617122 threshold for the closest match to the reported held-out protocol.
