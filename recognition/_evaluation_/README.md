# Face Recognition Evaluation

This directory contains benchmark evaluation scripts and supporting instructions:

- [IJB-B and IJB-C](ijb/README.md): 1:1 verification and 1:N identification scripts, with metadata and data access instructions.
- [MegaFace](megaface/README.md): links to the test suite and devkit; this directory also includes feature generation and noise removal scripts.

Follow each benchmark's instructions for datasets and model preparation. See [face recognition](../README.md) for training methods and [datasets](../_datasets_/README.md) for dataset references.
